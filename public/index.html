    Guía rápida para romperla

    1. Carga datos demo con npm run seed o agrega a tu primer colaborador.
    2. Genera una nómina desde el botón Nuevo ciclo y elige fechas/frecuencia.
    3. Ajusta percepciones en la tabla editable: bonos, deducciones, horas extra.
    4. Cierra el ciclo para bloquear ediciones y registrar la fecha de pago.
    5. Monitorea indicadores en el tablero de Inteligencia Operativa.

    Tip: puedes volver a abrir esta guía desde el botón “¿Cómo empiezo?” cuando quieras.
